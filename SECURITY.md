# Security Policy

Do not include passwords, access tokens, private keys, private network
addresses, serial captures, or host-specific build paths in issues, commits, or
pull requests.

Please report a suspected vulnerability through the repository's private
security advisory workflow. If that workflow is unavailable, open a minimal
issue without reproducing the sensitive value and ask for a private contact
channel.

The `public` branch is an initial publication snapshot and is not a supported
security release. Kernel images and board logs must be reviewed separately from
the source tree before publication.
